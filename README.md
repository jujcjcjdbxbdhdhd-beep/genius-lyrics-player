# Genius Live Lyrics for Android 🎵

Полнофункциональное Android-приложение, которое в реальном времени отслеживает воспроизведение музыки **в любом плеере на телефоне** (Spotify, Яндекс.Музыка, VK Музыка, YouTube Music, Apple Music, Poweramp и др.), находит текст песни на сайте **Genius.com** и автоматически прокручивает его во время прослушивания.

---

## 🚀 Ключевые возможности

1. **Автоматическое распознавание текущей песни из любого плеера**:
   - Работает через системный `NotificationListenerService`.
   - Мгновенно подхватывает смену трека, название и исполнителя без необходимости переключаться в приложение.
2. **Загрузка текста с Genius.com**:
   - Очистка заголовков (удаление мусора вроде `(Remastered)`, `[Official Audio]`).
   - Парсинг разметки Genius (`div[data-lyrics-container="true"]`).
   - Красивое выделение секций трека (`[Куплет 1]`, `[Припев]`, `[Интро]` и т.д.).
   - Автоматический кэш: просмотренные тексты сохраняются на телефоне и открываются мгновенно даже без интернета.
3. **Плеер с автопрокруткой (Auto-Scroll)**:
   - Плавная автоматическая прокрутка слов в такт треку.
   - Регулировка скорости (`0.5x`, `0.75x`, `1.0x`, `1.25x`, `1.5x`, `2.0x` и т.д.).
   - Быстрая пауза / возобновление в один тап.
   - Кнопка быстрого возврата к началу текста.
   - Изменение размера шрифта (`A-` / `A+`).
4. **Плавающее окно поверх всех приложений (Floating Window)**:
   - Можно включить плавающий оверлей, который будет отображаться прямо поверх Spotify, VK или Яндекс Музыки.
   - Окно можно перетаскивать по экрану пальцем, сворачивать и настраивать скролл.
5. **Ручной поиск**:
   - Поле поиска для быстрого нахождения текста любого трека вручную.

## 📦 Как получить готовый APK-файл

### Способ 1: Бесплатная онлайн-сборка через GitHub Actions (Самый простой, без установки софта)
В репозитории уже настроен рабочий CI/CD пайплайн (`.github/workflows/build-apk.yml`).
1. Загрузите этот проект в свой новый репозиторий на **GitHub** (можно приватный или публичный).
2. GitHub автоматически запустит сборку в разделе **Actions** (или нажмите **Actions -> Build Android APK -> Run workflow**).
3. Через ~1.5 минуты сборка завершится, и в блоке **Artifacts** появится готовый файл **`GeniusLyrics-App-debug.zip`**, внутри которого лежит `app-debug.apk`.
4. Перекиньте `.apk` на телефон и установите!

---

### Способ 2: Сборка через Android Studio
1. Скачайте и установите бесплатную [Android Studio](https://developer.android.com/studio).
2. Нажмите **Open** и выберите папку `genius-lyrics-player`.
3. Дождитесь автоматической синхронизации Gradle.
4. В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

---

### Способ 3: Сборка через терминал (если установлен JDK 17 и Android SDK)
Выполните в корне папки проекта:
```powershell
gradle assembleDebug
```
Готовый APK файл будет расположен в:
`app/build/outputs/apk/debug/app-debug.apk`

---

## 📱 Настройка и запуск на телефоне

1. Установите APK на ваш Android-смартфон (при запросе разрешите установку из неизвестных источников).
2. При первом запуске нажмите кнопку **«Предоставить доступ»** в красной плашке и включите переключатель **Genius Live Lyrics** в настройках «Доступ к уведомлениям» (Notification Access) Android. Это необходимо, чтобы приложение видело, что сейчас играет в Spotify/VK/Яндекс.
3. (По желанию) Для плавающего окна нажмите на иконку оверлея в верхнем правом углу карточки и разрешите «Поверх других приложений».
4. Включите любой трек в вашем любимом плеере — текст песни мгновенно появится на экране!
